# 🍔 Zymeal Frontend Web Application

The official web application frontend for **Zymeal Gourmet Food Delivery Platform**, built using **React, Vite, Lucide Icons, and Vanilla CSS design system**.

---

## 🚀 Live Demo & Production Deployment

- **Canonical Live URL**: [https://zymeal.vercel.app](https://zymeal.vercel.app)
- **Deployment Platform**: Vercel

---

## 🛠 Features & Design System

- 🌙 **Obsidian Dark & Light Glassmorphism**: Theme toggle with persistent `localStorage` preference.
- ⚡ **Express 30-Min Filter**: 1-click filtering for quick delivery food items.
- 🛒 **Interactive Steppers**: `- 1 +` quantity steppers and cart drawer.
- 💳 **Instant Checkout**: Indian Rupee (`₹`) price calculation, 5% GST tax, and free delivery on orders over ₹499.
- 📊 **Real-Time Order Tracking & Admin Console**: 3-second live polling sync for orders and revenue metrics.
